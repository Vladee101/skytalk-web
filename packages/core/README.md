# @skytalk/core

Pure domain logic for SkyTalk Web. No I/O, no UI — runs identically in Node and browser.

**Public API (coming in T-002+):** `validateFlightJson`, `validateInput`, `LessonStateMachine`, and all shared TypeScript types.

This package is a leaf: it imports nothing from `@skytalk/server` or `@skytalk/web`.
