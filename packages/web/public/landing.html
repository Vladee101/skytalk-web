// КАК ЭТО РАБОТАЕТ

Процесс радиообмена

Каждый шаг урока имитирует реальный обмен с Диспетчером. Инструктор — за пультом ATC, студент — в кабине пилота.

01 // СЛУШАТЬ

Команда Диспетчера

Инструктор дает команду голосом. Студент слышит её через наушники с эффектом радиостатики — как в реальном эфире.

02 // НАЖАТЬ

Зажать пробел

Удерживать ПРОБЕЛ — имитация нажатия кнопки PTT на штурвале. Это активирует микрофон и блокирует ввод.

03 // ГОВОРИТЬ

Ответный вызов

Произнести правильный ответ по фразеологии ICAO. Инструктор слышит голос студента чисто, без статики.

04 // ВВОД

Данные в поле

Если поле мигает синим — ввести требуемое значение (частоту, код, курс или высоту) и нажать ENTER.

05 // ЖДАТЬ

Подтверждение

После зеленой вспышки студент ждет. Инструктор решает когда переходить к следующему шагу.

Регулятор статики

Ползунок Radio % в нижней части экрана управляет громкостью радиошума — того, что слышите вы когда говорит инструктор.

0% — чистый голос. 60–70% — реалистичный эфир. 100% — тяжелые условия для продвинутой тренировки. Инструктор всегда слышит вас чисто — ползунок влияет только на вас.

// СОВЕТЫ

Как тренироваться эффективно

Несколько принципов которые ускорят прогресс.

👂 Сначала слушать

Не торопитесь нажимать ПРОБЕЛ. Сначала полностью поймите команду, затем отвечайте.

🔢 Фонетика цифр

"niner" а не "nine". "fife" а не "five". "tree" а не "three". Это не опечатки — это стандарт ICAO.

📡 Увеличивайте статику

Начните с 0%, постепенно поднимайте. К экзамену умейте работать на 70–80%.

📝 Полные фразы

"One one eight decimal seven zero" — не "One one eight point seven". Каждый слог важен.

⏳ Терпение

После зеленой вспышки — просто ждите. Темп сессии полностью у инструктора. Это намеренно.

📈 Регулярность

15 минут каждый день работают лучше, чем два часа раз в неделю.

Пропуск нулей — "118.7" вместо "118.70" не пройдет валидацию.
Ввод во время передачи — пока ПРОБЕЛ зажат, клавиатура заблокирована.
Слишком быстрый ответ — пауза после команды естественна и правильна. Диспетчер ждет.

SkyTalk намеренно ограничивает студента — одно поле ввода, отсутствие подсказок, инструктор управляет темпом. Это не недостаток.

В реальной кабине нет кнопки «следующий шаг», нет подсказок, нет возможности перемотать команду Диспетчера. Эти ограничения развивают именно те навыки, которые нужны в реальном полете.

// ПРОБЛЕМЫ

Устранение неисправностей

Если что-то пошло не так.

Нет звука от инструктора
Нажмите ПРОБЕЛ хотя бы один раз — это активирует аудиосистему браузера. Проверьте что браузер разрешил доступ к микрофону. Если не помогло — перезагрузите страницу (Ctrl+Shift+R).
Инструктор не слышит вас
Убедитесь что удерживаете ПРОБЕЛ во время речи. Проверьте индикатор TRANSMITTING в нижней полосе экрана. Проверьте разрешение микрофона в настройках браузера.
Поле ввода не реагирует
Дождитесь синего мигания — без него поле неактивно. Убедитесь что не зажат ПРОБЕЛ. Кликните в поле мышью.
Нет зеленой / красной вспышки
Убедитесь что нажали ENTER после ввода. Проверьте формат: точка вместо запятой, ведущие нули для частот, 4 цифры для squawk.
Страница не подключается
Ссылка действительна 24 часа. Попросите инструктора создать новую комнату. Используйте Chrome или Edge для лучшей совместимости.
Статика слишком громкая
Передвиньте ползунок Radio % влево в нижней части экрана.
