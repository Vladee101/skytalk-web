# @skytalk/web

React + Vite SPA for SkyTalk Web. Renders tutor and student session UIs, drives the Web Audio radio engine, and connects via PeerJS for WebRTC audio.

**Imports from:** `@skytalk/core` (workspace dependency).

**Build:** Vite (configured in T-030). Until then, `pnpm build` runs `tsc --noEmit` only.
